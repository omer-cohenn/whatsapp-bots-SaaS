## What to scan for
1. **Exposed secrets** — API keys, tokens, passwords, or the encryption key hardcoded in source
   files, committed `.env` files, or config files (Supabase key, Gemini key, Google OAuth creds).
2. **Unencrypted sensitive data at rest** — especially the WhatsApp/Baileys credentials saved as
   plain JSON on disk, and whether lead data is actually encrypted.
3. **Multi-tenant isolation gaps** — any DB query or endpoint that touches tenant data WITHOUT
   filtering by `business_id`/user. Cross-tenant leaks are critical.
4. **Missing authentication / authorization** — API endpoints with no auth check; the public
   booking page; admin/back-office routes.
5. **Input validation gaps** — unvalidated input from WhatsApp users or the frontend; injection risks.
6. **Logging leaks** — secrets, tokens, or raw personal data written to logs.
7. **Dependency / config risks** — obviously outdated or risky settings (CORS `*`, debug mode on, etc.).
